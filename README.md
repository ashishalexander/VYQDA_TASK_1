Monthly Task Tracker
A simple task tracking table built with React directly in an HTML page.
What it does

Displays a list of tasks with 6 editable columns
Allows users to edit any cell by clicking on it
Prepares data for API submission (no actual submission)

How it's built

React loaded directly via CDN (no Node.js or npm)
Single HTML file with embedded JavaScript and CSS
Babel for JSX support

How to use

Open the HTML file in any browser
Click on any cell to edit
When you click outside the cell, data is updated and prepared for API
